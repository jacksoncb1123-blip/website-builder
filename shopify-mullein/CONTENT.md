## 7) DAWN SETUP — STEP BY STEP

1. **Use the Dawn theme**
   - Online Store → Themes. If Dawn isn't there: "Add theme" → "Theme library" →
     add **Dawn**. Leave it as a **draft/unpublished** theme for now (you'll
     preview, not publish).

2. **Set the colors (white + green)**
   - In Themes → Customize → **Theme settings (gear icon) → Colors**.
   - Set a scheme with Background `#FFFFFF`, Text `#1A1A1A`, and
     Buttons/Accents/Links to green `#2E7D32` (hover `#1B5E20`).
   - Apply that scheme to your header, buttons, and sections.
   - (Optional) Theme settings → Typography: a clean sans (e.g., Assistant /
     Inter-like) for the minimal wellness feel.

3. **Add the product** (Products → Add product) using Section 1 above. Set price
   `24.99`, add images, keep **Draft** until launch.

4. **Create the pages** (Online Store → Pages → Add page):
   - **About** → paste Section 3.
   - **Contact** → paste Section 6, and set Template to **page.contact**.
   - **Shipping Policy / Refund Policy** → easiest via **Settings → Policies**
     (paste Sections 4 & 5); they'll auto-link in the footer. (Or make them
     regular pages.)

5. **Build the Home page** (Themes → Customize, Home template) by adding the
   sections in Section 2 and pasting the text.

6. **Navigation** (Online Store → Navigation):
   - **Main menu:** Home · Shop (→ product) · About · Contact
   - **Footer menu:** Shipping Policy · Refund Policy · Contact

7. **Add the custom CSS** (optional polish) — see `dawn-custom.css` in this
   folder for the snippet and where to paste it.

## 8) KEEP IT PRIVATE UNTIL YOU REVIEW

Two layers so nothing goes live early:
- **Keep the product/pages as Draft / the theme Unpublished**, and use
  **"Preview"** in the theme editor to review.
- **Password-protect the storefront:** Online Store → **Preferences** → enable
  **"Restrict access … with a password."** Customers can't see the store until
  you remove it. Publish only when you're ready.
